Initial Public Release

  • 「皇統皇胤図」として初回公開。
  • 完全図を公開用HTMLとして整備。
  • 青・紫・橙・緑等の線種と婚姻等関係節点の意味を公開用凡例に整理。
  • 皇籍離脱・臣籍降下後の人物を破線枠で区別する表示を整理。
  • 東伏見慈洽を「東伏見慈洽（邦英王・東伏見邦英）」として整理し、臣籍降下後の身分を表示。
  • 後冷泉天皇から高階為行を経る補完血統経路を追加。
  • 近現代民間人について公開情報を超える個人情報探索を行わない方針を明文化。
  • 公開直前 validator：エラー0件、警告0件。

バージョン方針
