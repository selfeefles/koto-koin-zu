# 皇統皇胤図 v4.2.8 公開用凡例

## 系譜線

- **青太線**：神武天皇から今上天皇に至る男系男子の系譜経路。
- **紫太線**：男系でつながる皇族女性を経由し、現皇統へ至る系譜経路。
- **橙太実線**：青・紫では表れない補完系譜の皇室・皇親側区間。
- **橙太破線**：臣籍等を経由する補完系譜区間。
- **緑太破線**：明治天皇以降の皇女を介して旧宮家へつながる近代系譜。
- **灰破線**：養子・猶子・実親子とは別に扱われた親子関係等。
- **灰細線**：その他の系譜上の親子関係。

## 人物・記号

- **婚姻等関係節点（●）**：婚姻、皇后・妃・側室その他、系譜上表示する必要のある関係をまとめる節点。子がある場合は、その子へ接続する。子がない場合は二人の関係のみを示す。個々の関係が制度上同一であることを意味しない。
- **破線枠**：臣籍の人物・皇籍離脱後の人物。元の枠色は人物区分に応じて保持する。
- **紫枠**：女性天皇・皇族女性など、本図で皇室・皇親側として扱う女性。
- **赤枠**：皇室外から系譜に入る女性（后妃等）。

歴代天皇（北朝を含む）の太枠は視認性を高めるための表示で、独立した系譜上・制度上の意味を持つ凡例項目とはしない。

## 婚姻により皇族の身分を離れた女性の表記

婚姻後の最終的な名前を `name`、皇族であった時の名前を `alias` とする。full では alias を括弧内に表示する。

例：**黒田清子（紀宮清子内親王）**

対象人物は紫枠を維持しつつ、婚姻後の身分を示すため枠線を破線とする。

この凡例は図の読み方を示すものであり、皇位継承資格や制度上の正統性を示すものではない。
