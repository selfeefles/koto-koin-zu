# 皇統皇胤図

皇統・皇胤の系譜を可視化した個人の自由研究です。

## 初回公開手順
1. GitHubで公開リポジトリを作成（例 `koto-koin-zu`）。
2. このフォルダの中身をリポジトリ直下へアップロード。
3. Julia生成の公開用完全図HTMLを `full.html` に差し替え。
4. `Settings` → `Pages`。
5. `Source` = `Deploy from a branch`。
6. Branch=`main`, Folder=`/(root)` を選択。
7. 表示されたPages URLを確認。

`.nojekyll` は静的HTMLをそのまま公開するために同梱しています。

## 注意
個人情報、非公開資料、再配布権限のないスキャン画像などは公開リポジトリへ入れないでください。
