**Initial Public Release — 2026-08-15**

## 注意

本図は宮内庁が編纂する公的な「皇統譜」そのものではありません。また、現行制度上の皇位継承資格、皇族身分、家格その他の法的・制度的地位を示すものではありません。

古代には伝承的な系譜・伝承紀年を含み、後世についても史料上の確実性には差があります。不確実・不詳・異説のある事項は、品質区分や注記で可能な限り区別しています。

近現代の民間人については、系譜確認に必要な公開情報のみを収録し、公開系譜を超える個人情報探索は行いません。自己申告や出典不明の「皇胤」「旧皇族の末裔」等の主張のみを根拠として新規収録することは想定していません。

v4.2.8 は初回公開版として固定し、修正が必要な場合は後続バージョンで行います。
